## 1. 技术栈判定

| 层 | 原站技术 | 证据 |
|----|----------|------|
| 前端 | **uni-app (Vue2 语法) H5 端** | DOM 出现 `UNI-VIEW / UNI-TEXT / uni-tabbar__item` 类名；资源为 `pages-xxx.js` 分包 |
| 前端构建 | Vue CLI（非 Vite） | `chunk-vendors.a85fd366.js`、`static/index.e8e070f7.css` 哈希命名 |

## 4. 核心交互与点击事件（已验证）

| 交互 | 行为 |
|------|------|
| 未登录点「我的」 | 显示 登录/注册 入口 + 静态菜单 |
| 登录页 | 输入手机号+密码 → 勾选协议 → 登录 → POST `/api/user/login` → 返回 token 存本地 → 跳转首页 |
| 首页筛选 | 即将开售/已开售切换 + 类型下拉（系列）→ 重新拉商品列表 |
| 首页标签 | 推荐/热榜/排行 三标签（getSeries type=10/20 区分） |
| 市场 Tab | 藏品/盲盒/关注/排行 四子页切换；表头可排序 |
| 发现 Tab | 分类图标横滑筛选消息（affichetypelist） |
| 登录按钮协议 | 未勾选时按钮为禁用态（灰粉色） |
| 公告 | 点击进入 noticeDetails 详情 |

## 5. 已捕获 API 响应结构（样例）

### /api/user/login（POST {account,password}）
```json
{ "code": 1, "msg": "登录成功", "data": { "userinfo": { "id": 173634, "nickname": "175****1293", "mobile": "...", "avatar": "/defautAvatar.png", "score": 0, "inviter_code": "HT173634", "token": "uuid", "expiretime": ..., "expires_in": 2592000 } } }
```
- 鉴权：请求头 `token: <uuid>`，30 天有效

### /api/index/getConfig
返回约 40 个系统配置项：appName、appLogo、pay_time_limit=300s、default_pay_type=huifu、h5_invite_url、resell_collection(寄售开关=1)、transfer_collection(转赠=1)、协议开关等

### /api/index/getSeries?type=10|20
系列列表（type=10 藏品 tab，20 盲盒）：内置 推荐(-1)、我的关注(-2)、全部(0) + 业务系列（series_id、resale 时段控制、pattern）

### /api/index/afficheList
公告分页：id/title/image/createtime/type/affiche_type

### /api/banner/show/getBanner
轮播图：id/image/url/url_type/is_show

### /api/market/market/getMarketList
市场列表：id/name/series_id/listimg/total_num/reprice_limit(限价)/deal_num/min_price/is_like/market_fluctuate(涨跌)/goods_type + 嵌套 product

### /addons/signin/api.index/index
签到：每日分数 s1..s7=1..7、补签 fillupscore=100/3天、排行榜

### /addons/diypage/index
可视化装修页面配置（JSON 模块流：menu 等组件）——说明首页部分区块由后台装修系统配置

## 6. 风险与注意

- 原站部分接口需要有效 token / 业务数据，空账号返回空列表（如合成、寄售）
- `img.hnyiqin.asia` OSS 旧对象可能 404（NoSuchKey），下载图片需以实际页面渲染出的 URL 为准
- 支付类接口（huifu/sandpay/yibao）复刻时以 mock/沙箱模式实现，不接真实资金通道
