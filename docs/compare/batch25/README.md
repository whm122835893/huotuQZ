## 边界登记（非阻断，如实记录）

### P107 / P110 MAE 偏高（10.77 / 10.79）
两页整页/顶部为原站大尺寸 PNG 背景图（rank_bg 1170×2532、invite-friends 396×342），
本地 Chromium 与原站 WebView 的图像插值缩放存在细微差异，导致整图 MAE 偏高。
文字层（1/1、15/15）与几何层（0/3、0/13）全部 0 fail，并排图肉眼一致，
属既定可接受的图片渲染差异。P110 顶部邀请机器人图原站为裁切放大显示，
clone 按比例缩放至 303×120，机器人大小有轻微差异，不影响功能与骨架一致性。

### P110 app-logo.jpg 404
原站 `17b679f0562f639f96344f08e59e0729.jpg` 返回 404（侦查 BAD_IMAGES 实测），
忠实复刻为 48×48 灰块占位（rgb(242,244,247)，br12），与原站破图态视觉一致。

### P108 / P112 / P113 空页
三页原站均为真实空态（ranking 空 data / 无 url 参数 webview），
clone 复刻为白底空页；原生 `uni-page-head` 返回箭头为框架层，按既定口径 SKIP。

### P111 动态态
启动页为静态启动图，「跳过」静态可点（clone 跳转首页）。原站启动页通常带倒计时，
无参数直访 2.6s 稳定态为跳过按钮常驻，按稳定态快照复刻。
