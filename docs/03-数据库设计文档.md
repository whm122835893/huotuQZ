# 火兔复刻项目 — MySQL 数据库设计文档 v1

> 依据：原站 API 响应字段逆向 + 页面功能推断。字段以 API 实际返回为准，后续逐页验收时持续校准。
> 引擎 InnoDB / utf8mb4；ThinkPHP 6 迁移约定：表名 `fa_` 风格改为本项目 `ht_` 前缀。

## 1. ER 总览（核心域）

```
user ─┬─ user_token            （登录态）
      ├─ user_collection ──┬── collection（商品/藏品 SKU）
      │                    └── order ── pay_record
      ├─ consignment(寄售) ── collection
      ├─ beg_buy(求购)
      ├─ user_money_log / user_score_log
      └─ invitation_relation（邀请）

series ── collection ── collection_chain（链上序号）
blind_box ── blind_box_goods ── collection
synthesis_theme ── synthesis_scheme ── synthesis_material ── collection
banner / affiche / affiche_type / config / diypage
signin_log / lottery_* / regift_order
```

## 3. 关键索引

- ht_user：UNIQUE(username), UNIQUE(mobile), UNIQUE(inviter_code), KEY(inviter_user_id)
- ht_user_collection：KEY(user_id,status), KEY(collection_id,status), UNIQUE(collection_id,serial_no)
- ht_consignment：KEY(collection_id,status), KEY(user_id,status)
- ht_order：UNIQUE(order_sn), KEY(buyer_id,status), KEY(seller_id,status)
- ht_market_fluctuate_log：UNIQUE(collection_id,day)
- ht_affiche：KEY(affiche_type_id), KEY(user_id,type)
